# DHCP

## Definition
DHCP stands for Dynamic Host Configuration Protocol. It automatically assigns IP addresses and other network settings to devices.

## Why it exists
- It saves time and avoids manual configuration.
- It prevents IP conflicts.
- It helps devices join the network easily.

## Simple explanation
DHCP is like a receptionist giving each guest a room and a pass.

## What it provides
- IP address
- Subnet mask
- Default gateway
- DNS server address

## Process
1. Client sends DHCP Discover
2. Server responds with DHCP Offer
3. Client requests the offered address
4. Server confirms with DHCP Ack
