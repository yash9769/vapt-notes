# DHCP

## Definition
DHCP stands for Dynamic Host Configuration Protocol. It automatically assigns IP addresses and other important network settings to devices when they join a network.

## Why it exists
- It removes the need for manual IP configuration.
- It prevents IP conflicts.
- It helps new devices connect quickly to a network.

## Simple explanation
DHCP is like a receptionist in an office building.
- a new visitor arrives
- the receptionist gives them a room number and access details
- the visitor can then enter the network smoothly

## What DHCP provides
- IP address
- Subnet mask
- Default gateway
- DNS server address
- Lease time

## DHCP process
1. DHCP Discover
   - The client asks, “Is there a DHCP server available?”
2. DHCP Offer
   - The server replies with network details.
3. DHCP Request
   - The client asks to use the offered information.
4. DHCP Acknowledgment
   - The server confirms the assignment.

## Real-world example
When you connect your laptop to Wi-Fi:
- the laptop asks for network settings
- the DHCP server assigns an IP address
- the laptop can then access the internet

## Common interview points
- What is DHCP?

## Common mistakes
- Thinking DHCP assigns only the IP address.
- Forgetting that it also provides gateway and DNS details.
- Assuming DHCP is only used in large networks.
