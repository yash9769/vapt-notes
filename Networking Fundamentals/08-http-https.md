# HTTP and HTTPS

## Definition
HTTP and HTTPS are application layer protocols used to transfer web data between client and server.

## Why they exist
- HTTP allows websites to be requested and delivered.
- HTTPS adds security using encryption.
- Without them, websites would not work properly over the internet.

## Simple explanation
- HTTP = normal web traffic
- HTTPS = secure web traffic

## Difference
| Protocol | Port | Security | Use |
|---|---|---|---|
| HTTP | 80 | No encryption | Basic web traffic |
| HTTPS | 443 | Encrypted | Secure websites |

## Interview points
- What is the difference between HTTP and HTTPS?
- Which port does HTTPS use?
- Why is HTTPS better?

## Quick revision
- HTTP = port 80
- HTTPS = port 443
- HTTPS is secure because it uses encryption
